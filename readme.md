# Pegs Music Player

A sleek and functional music player application built with Python. This application allows users to manage their music library and enjoy a seamless audio experience.

## Features

- **Library Management:** Easily scan and organize your local music files.
- **Playback Controls:** Standard play, pause, stop, next, and previous functionality.
- **User Interface:** Intuitive and modern UI for easy navigation.
- **Format Support:** Compatible with popular audio formats like MP3, WAV, and FLAC.

## Prerequisites

Before running the application, ensure you have the following installed:
- Python 3.x
- GTK4
- gstreamer1.0
- ladspa plugins(replaygain, compressor SC4, limiter )

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pegasusict/pegs-music-player.git
   ```
2. Navigate to the project directory:
   ```bash
   cd "Pegs Music Player"
   ```
3. Run the application:
   ```bash
   python main.py
   ```
